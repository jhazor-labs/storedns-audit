What a DNS scan can't see

These checks read public DNS records only. They cannot see inside your Shopify admin. Verify these yourself, they matter as much as anything above:

  • Two-step authentication on every staff account. Shopify admin → Settings → Users. This is the single highest-impact store security setting.
  • Staff permissions. Remove ex-collaborators, limit each account to what it needs.
  • Installed app review. Apps get API access to your store data. Uninstall anything you don't use.
  • Unique, strong password on the store owner account, stored in a password manager.

Method: DNS queries are resolved in your browser via Google Public DNS (dns.google) with Cloudflare (cloudflare-dns.com) as fallback, both over HTTPS. Verdict criteria for Shopify-specific records follow Shopify's published help documentation. Email standards follow RFC 7208 (SPF) and RFC 7489 (DMARC).

This report covers DNS configuration only and is not a full penetration test or a guarantee of security.
